## 📖 Sobre o projeto

Este projeto consiste no desenvolvimento de um website para uma barbearia, com o objetivo de oferecer uma presença digital moderna, funcional e intuitiva.

A plataforma permite que os clientes conheçam os serviços oferecidos, consultem os preços, visualizem os cortes disponíveis e realizem agendamentos diretamente pelo WhatsApp.

O projeto foi desenvolvido como parte da minha evolução nos estudos de desenvolvimento Front-End.

---

## 🚀 Funcionalidades

- 💈 Galeria de cortes de cabelo.
- 💰 Tabela de preços dos serviços.
- 📱 Layout responsivo.
- 📍 Integração com Google Maps.
- 📲 Agendamento via WhatsApp.
- 🧭 Menu de navegação.
- 📖 Seção de apresentação da barbearia.
